CONTROLE DE EPI'S

Controle de Epi's

Descrição

Projeto desenvolvido para criação de uma página web com Java, Springboot, Thymeleaf, HTML, CSS e JavaScript.
Foi desenvolvido para aprofundar nos conceitos em java web com Spring, e criação de um CRUD completo.
A maior dificuldade encontrata foi o desenvolvimento do emprestimo de epis, pois tinhamos que verificar se o usuario java estava com algum equipamento emprestado com ele, e outra dificuldade foi na manipulação de datas dentro do banco de dados.

Java 17 Spring Boot Thymeleaf MariaDB HTML CSS JavaScript
